
# Taller Streamlit - Valoración de Activos

## Descripción
Aplicación en Streamlit para comparar:
- Movimiento Browniano Geométrico (GBM)
- Heston
- Saltos de Merton

Incluye:
- Backtesting con RMSE
- Simulación Monte Carlo
- Proyección a un mes
- Recomendación ejecutiva
- Módulo de Opciones Reales

## Instalación

pip install -r requirements.txt

## Ejecución

streamlit run app.py
